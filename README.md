# shiju
Use OCR technology to recognize text, then save and archive it.

# 打jar
jnativehook,pom上依赖无法引入,需要本地执行
mvn install:install-file -Dfile="C:\Users\yan10\Downloads\jnativehook-2.2.0.jar" -DgroupId=com.github.kwhat -DartifactId=jnativehook -Dversion=2.2.0 -Dpackaging=jar

# 打 exe 文件
将jar打成exe 使用 launch4j , https://launch4j.sourceforge.net/
